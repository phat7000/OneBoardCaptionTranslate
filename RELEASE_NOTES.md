# OneBoard Caption Translate 1.0.0

First stable OneBoard release for Windows x64.

## Highlights

- Lightweight real-time translation built on Windows Live Captions.
- Multiple translation providers retained, with Google available for quick-start testing.
- Two-pane Original / Translation overlay, with Original on top and Translation on the bottom by default.
- Switch Order, Original Only, and Translation Only modes.
- Font, color, outline, background, opacity, and click-through controls.
- Translation history and CSV export.
- Per-user settings and history under `%LOCALAPPDATA%\OneBoard\OneBoard Caption Translate\`.
- Self-contained portable/no-install package and per-user Windows installer.

## System requirements

- Windows 11 22H2 or newer with Windows Live Captions is required.
- The portable package is self-contained; no separate .NET installation is required.

## Release information

- Automatic updates are disabled in v1.0.
- Official source: https://github.com/phat7000/OneBoardCaptionTranslate
- Upstream: https://github.com/SakiRinn/LiveCaptions-Translator
